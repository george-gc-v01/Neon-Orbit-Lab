# Third-party components and build tools

The application source uses no additional NuGet packages. It depends on Microsoft .NET, WPF and Windows Forms and calls Windows system APIs. The self-contained distribution includes runtime components with their original Microsoft/.NET licence and third-party notices; preserve notices shipped in the published output and verify them before distributing a public release.

The original N icon and orbital artwork are generated by project source. No third-party images, fonts or copied application assets are bundled. Segoe UI and Consolas are used from Windows.

Build tools: Microsoft .NET SDK; Node.js for icon regeneration; Inno Setup 6 for the installer; GitHub actions/checkout, setup-dotnet and upload-artifact for CI. These are build dependencies, not included application source. Review the versions' official licences before packaging any of their components.
